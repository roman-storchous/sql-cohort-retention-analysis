# Когортний аналіз та оцінка Retention Rate (SQL + Google Sheets)

Мета проєкту — проаналізувати поведінку користувачів у часі (протягом 6 місяців) та оцінити показник утримання (Retention Rate). Також порівнюється поведінка користувачів, які прийшли через промо-акції (`promo_signup_flag = 1`), та тих, хто зареєструвався органічно (`promo_signup_flag = 0`).

---

## Що було зроблено:

1. **Очищення даних та SQL-запит:**
   * Обробка та стандартизація дат реєстрації та подій, які зберігалися у базі в різних текстових форматах (з різними розділювачами та різною довжиною року).
   * Фільтрація тестових подій (`test_event`) та записів із порожніми значеннями (NULL).
   * Розрахунок місячного зсуву (`month_offset` від 0 до 5) для визначення стажу користувача в продукті.
   * Агрегація даних у підсумкову таблицю за параметрами: промо-статус, місяць когорти та місячний зсув.

2. **Візуалізація в Google Sheets:**
   * Побудова зведеної таблиці з загальною кількістю унікальних користувачів по когортах.
   * Створення когортної таблиці Retention Rate (%) з автоматичним розрахунком відсотка утримання відносно 0-го місяця.
   * Налаштування умовного форматування (теплова карта) для швидкого виявлення точок відтоку.
   * Додавання інтерактивного зрізу (Slicer) для зручного перемикання між Усіма користувачами, Промо та Органікою.

---

## Ключові результати та висновки:
* Найбільший відтік користувачів відбувається між 0-м та 1-м місяцями після реєстрації.
* Органічні користувачі показують вищий рівень довгострокового утримання (Retention Rate) порівняно з тими, хто прийшов через промо-кампанії.
